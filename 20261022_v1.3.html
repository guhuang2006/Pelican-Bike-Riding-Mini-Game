没有一张图片，全是盒子

整段动画由 div、border、渐变和关键帧拼成：公路是三层速度不同的传送带，踩踏的两条腿是用余弦定理解出来的 12 帧骨骼；换成滑板或电动车时，同一套腿骨切换为站姿静态角度，鸟身整体平移对齐踏板。三种坐骑 × 三种座驾 × 四种天气，再加一个藏了 14 次点击的世界线彩蛋与一枚「显示其他鸟类」开关，依旧没有一行 JavaScript。

2车轮 = 一圈 border

轮胎是 border，辐条是 repeating-conic-gradient，轴心是 ::after。滑板轮、电动车轮只是把半径和转速换了参数。

repeating-conic-gradient(#cfd3dc 0 2.4deg, transparent 2.4deg 45deg)

3公路是一条无限传送带

草丛最快、路灯长椅中速、云最慢——速度差就是“在前进”的错觉。每层内容复制两份，滚过一个周期宽度后无缝接上。

@keyframes kBelt { to { transform: translateX(-1000u) } }

4微表情与纯 CSS 计数器

眨眼 4.6 秒一次，喉囊 2.6 秒晃一下。彩蛋的“14 次点击”是纯 CSS 的 radio 链：14 层透明 label 叠在鹈鹕身上，同组 radio 互斥所以选中下一格自动清除上一格；进入彩蛋会顶掉 g14（按钮随之消失），「回到原世界线」一键选回 g0 完成复位，可无限次再触发。

#g14:checked ~ .stagewrap .eggbtn { opacity: 1 }
